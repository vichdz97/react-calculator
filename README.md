# React Calculator App

> [!NOTE]
> Last updated May 23, 2025

## Summary
A simple calculator application built using React and Tailwind CSS that performs various mathematical operations.

## Live Demo
The second version of the app is still in development, but you can access the live demo of the first version [here](https://vichdz97.github.io/projects/calculator-app/index.html).

## Technologies Used
- [React](https://react.dev) (*v18.2.0*)
- [TypeScript](https://www.typescriptlang.org) (*v5.0.2*)
- [Tailwind CSS](https://tailwindcss.com) (*v4.1.7*)
- [math.js](https://mathjs.org) (*v13.0.3*)
